# Vendored UIForma Kit

Copied from [XileHorizon/UIFormaKit](https://github.com/XileHorizon/UIFormaKit) `src/ui/` at commit `86a2733`.

The Kit is not published to npm yet, so the Studio keeps a copy of the components it uses. Treat these files as
read-only. When the Kit changes, copy the same files over again instead of editing them here. Studio-specific sizing
lives in `src/index.css` under `.studio-ui`, mostly as Kit token overrides.

Files: `Button`, `ButtonBlock`, `ColorChip`, `FieldRow`, `IconLabel`, `NumberField`, `SegmentedControl`, `Select`,
`SettingsSection`, `SidebarSlider`, `Slider`, `Switch`, `SwatchGroup`, `TextField`, `Dropdown`, their CSS, and
`tokens/tokens.css` plus `tokens/components.css`.
